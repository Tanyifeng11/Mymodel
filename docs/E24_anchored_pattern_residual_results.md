# E24：E5 锚定的纹样 residual 实验结果

E24-A 的安全性成立，E24-B 的方向语义控制不成立。按照预先规定的顺序，未启动 E24-C period，也未训练 identity。不能把这一结果表述为新的纹样控制方法已经成功。

## 实验设置

- E5 的正向条件 token 完整保留，只加由参考纹样方向驱动的 16×768 residual；CFG 负向条件不变。新增分支从零初始化，只训练该分支，原生成器保持冻结。
- A：600 步，扩散目标加背景与边界的 conditional epsilon 对 E5 的 stop-gradient 保持损失。B：在 A 通过后继续 600 步，使用同草图、同文本、同配色、参考旋转 90° 的合成目标对，增加可微的目标方向监督及成对背景／边界一致性。
- 训练参考 48 对，频率为 3、5、8、12；验证参考 32 对，频率为 6、7、9、11、13、15。验证使用种子 42、43、50 步 DDIM、CFG 7，按参考案例做 bootstrap 置信区间。验证图像总数为每阶段 128 张。
- E5 重新计算的条件 token 与 E23-M 保存值的最大绝对误差为 0；零 residual 的 E5 图像与既有 G0 逐像素一致。冻结模块哈希检查通过。mask 后端为 OpenCV。

## 预定 Gate 与结果

安全 Gate：相对 E5 的 leakage 增量的 95% CI 上界不超过 0.02，Sketch IoU 和 Edge F1 增量的 95% CI 下界不低于 −0.02，同时衣身内部 conditional score 变化 RMS 大于 1e−4。B 的主 Gate 另要求 paired flip 显著高于 E5。

| 阶段 | leakage 增量，均值 [95% CI] | Sketch IoU 增量 | Edge F1 增量 | 内部 score RMS | 安全 Gate |
| --- | ---: | ---: | ---: | ---: | --- |
| A，32 案例 | +0.000335 [0.000079, 0.000607] | +0.004058 [0.002328, 0.005847] | +0.001021 [−0.000421, 0.002400] | 0.001672 | 通过 |
| B，32 案例 | +0.000193 [−0.000229, 0.000864] | +0.005146 [0.003198, 0.007403] | +0.001720 [0.000210, 0.003150] | 0.002224 | 通过 |

E5 的 baseline leakage 为 0.005917、Sketch IoU 为 0.894507。A 的 8 案例 pilot 也通过安全 Gate，之后才运行 32 案例确认与 B。

**方向主 Gate 失败：**E5 与 B 的 paired flip accuracy 均为 0，成对增益为 0 [0, 0]。B 的方向读出有效率约 0.602，故不能把零翻转简单解释为全部输出不可读；即使只看最终生成图，也没有观察到要求的参考旋转导致输出旋转。B 的平均方向误差约 50.12°，E5 约 48.83°。

## 解释与边界

该实验证明，在当前 E5 条件接口和合成条纹协议中，附加小 residual 可以产生非零衣身内部响应，同时把背景与结构指标保持在 E5 附近。这只解决了“安全存在”问题。配对方向监督没有带来可测的最终方向翻转，说明当前仅由全局方向特征投影到 residual token 的机制不足以建立参考纹样的因果语义控制。
