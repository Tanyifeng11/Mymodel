# E18 阶段总结：联合对齐、方向可学习性与 fused-only 验证

截至 2026-09-26，已完成 E18 第一轮、E18.1 和 E18.2。保留本文件名，后续结果统一追加在此。E18-C/D 与 E18.3 均未开展。

## E18 第一轮：BF 与 readout 联合对齐

实验日期：2026-09-26。代码：`codex/e18` 分支，提交 `a8a76bc`、`8da626b`。服务器作业 `114003` 已完成，退出码 `0:0`；结果位于 `/share/home/u2515283058/Mymodel/e18/`。

### 问题与停止条件

E17 发现，BF 的部分来源特征有纹样线索，但完整 fused、最终 token 和生成图缺少一致的方向语义。E18 第一轮只检验：**同时训练 BF 后段与 readout，并加入方向对齐目标，能否让 fused 和最终 texture token 在独立验证集上同步获得方向语义？**

预设比较 B0（联合训练对照）与 B1（相同联合训练，加 orientation alignment）。只有 B1 在 fused 和 final token 均明显优于 B0，才进入 E18-C 的生成利用训练；C 成功后再做 E18-D 完整生成。

### 数据与训练

Pattern-Gold 从 E14 已核对缩略图的验证集候选构建，固定为 31 张图：10 个方向明确的条纹参考各含原图和 90° 旋转，另含条纹、格纹、波点等类别参考；标注了 4 对视觉上色调接近、类别不同的候选。构建时检查像素哈希，方向探针对同一原始参考的两种旋转版本整体留出。训练只使用 BF training split，Pattern-Gold 不参与训练。

4 对候选只经视觉检查和灰度直方图比较，**尚不能严格称为逐对同色异纹**；`source_group` 也只是临时样本分组，真实面料来源身份尚未核验。较广的独立验证沿用 E17 协议，横/竖方向任务为 120 个样本、三折评估。因此 Gold 是更明确的小型方向诊断集，不是严格按真实面料来源留出的最终测试集。

B0、B1 均从同一个 E17 `select` direct readout 检查点出发，使用相同训练样本选择、随机种子、500 步和优化设置。联合更新 BF stage3/4、对应 source projection 和 direct readout；冻结 BF stage1/2、CLIP、U-Net、TCPM。两组均通过蒸馏原 E5/GAM texture tokens 保留原有 token 行为；B1 额外对 fused 和 final token 加方向监督对比及两层关系对齐。每个训练参考同时使用原图与 rot90，并施加相同颜色扰动，避免颜色直接标识旋转标签。

训练确实发生：B0 的保留损失从约 0.513 降至 0.041；B1 从约 0.513 降至 0.052，方向损失从约 4.50 降至 3.98。损失下降本身不构成独立方向语义已学成的证据。

### 独立验证结果

表中方向探针均为 balanced accuracy，0.5 约为随机水平。Pattern-Gold 方向任务含 10 个原始参考的 20 个原图/旋转样本。

| Pattern-Gold 方向探针 | E5/GAM | E17 select | B0 | B1 |
| --- | ---: | ---: | ---: | ---: |
| CNN3/4 | 0.60 | 0.60 | 0.60 | 0.55 |
| fused | 0.55 | 0.55 | 0.50 | 0.50 |
| final token | 0.60 | 0.55 | 0.60 | 0.60 |
| 原图 FFT | 0.90 | 0.90 | 0.90 | 0.90 |

| 较广验证集 / 旋转响应 | B0 | B1 |
| --- | ---: | ---: |
| fused 方向 linear | 0.537 | 0.549 |
| fused 方向 MLP | 0.516 | 0.514 |
| final token 方向 linear | 0.562 | 0.514 |
| final token 方向 MLP | 0.526 | 0.495 |
| 原图 FFT 方向 | 0.802 | 0.802 |
| final token `D_rot` | 0.0761 | 0.0928 |
| U-Net `R_rot` | 0.0318 | 0.0237 |

B1 的 fused 线性探针仅比 B0 高 0.012，而 final token 反而低 0.048；Gold 上两层也没有优于 B0。`D_rot` 增大说明 token 对旋转更敏感，但 `R_rot` 未同步提高，更不能由此推断方向语义或生成跟随已经改善。

### 阶段判断

**E18-B 未通过预设门槛。**这次方向对齐目标没有建立 `BF/CNN → fused → final token` 一致的方向语义链路，因此按停止条件未启动 E18-C 的 matched-reference 服装内部 denoising 优势训练，也未运行 E18-D 的完整生成、方向跟随及结构质量评估。本轮没有 E18 生成结果，不能对生成改善或 Sketch IoU 作新结论。

当前只能说：**这组数据、损失权重、训练预算和后段 BF/readout 更新范围下，B1 没有优于联合训练对照。**不能据此证明 BF 架构本身不适合方向纹样；方向目标优化不足、训练标签噪声、Gold 规模以及来源分组未严格核验，仍是可能的限制。下一步应先解决 B 阶段的可学习性与独立验证问题，再按原门槛决定是否进入 C。

服务器可复核文件：`e18/gold/manifest.json`、`e18/train_selection.json`、`e18/b0/train_report.json`、`e18/b1/train_report.json`、`e18/gold_probe_{gam,e17_select,b0,b1}/report.json`、`e18/validation_{b0,b1}/report.json`、`e18/final_probe_{b0,b1}/report.json`、`e18/response_{b0,b1}/report.json`。模型检查点分别为 `e18/b0/joint_model.pt` 和 `e18/b1/joint_model.pt`。

## E18.1：Direction Learnability Sanity Check

代码提交：`811409e`、`af8fc65`。训练及初始探针作业 `114005`、补充几何评估作业 `114006` 均为 `COMPLETED / 0:0`。结果根目录为 `/share/home/u2515283058/Mymodel/e18_1/`。

### 设置：只用干净条纹检查监督是否可学习

复用 E14 的受控图案生成规则，构建方向确定的横/竖条纹。训练集为 48 个模板及各自的 rot90，共 96 张；验证集为 16 个模板及各自的 rot90，共 32 张。每对旋转图的颜色、亮度、前景占比完全相同，四种配色在方向上严格平衡；训练保留成对相同的亮度/对比度扰动。

| 划分 | 每幅图的条纹周期数 | 相位 |
| --- | --- | --- |
| 训练 | 3、5、8、12 | 0、0.23、0.47 |
| 验证 | 4、10 | 0.11、0.36 |

验证频率和相位均不参与训练。B0、B1 从相同 E17 select 检查点出发，训练模块、损失及权重完全沿用 E18：500 步、seed 42、AdamW 学习率 `2e-5`。本节 B0/B1 指**干净条纹上重新训练的对照**，不是上一节真实 BF 数据上的模型。没有修改 U-Net，没有跑生成。

线性探针的 StandardScaler、PCA（最多 8 维）及 LogisticRegression 仅在训练模板上拟合，再测试留出频率/相位。结果如下：

| 留出集方向 balanced accuracy | 起始检查点 | B0 | B1 |
| --- | ---: | ---: | ---: |
| CNN3/4 | 0.8438 | 0.8750 | 0.8750 |
| fused | 0.9688 | 0.9688 | 0.9688 |
| final token | 0.9688 | 1.0000 | 1.0000 |

**起始检查点已有很高的受控条纹可解码性，存在准确率天花板。**不能把 B1 的高探针分数当成方向监督新学到语义的证据，也不能据此直接宣布进入生成利用阶段。

### 补充评估：原方向目标能否改变留出集几何

由于探针触及天花板，训练结束后补充评估原方向目标及余弦 margin，未追加训练、改 loss 或调权重。这里的 fused 几何具体指：CLIP 与 CNN1–4 五个来源各自的 token 均值/标准差等权平均，再拼接并做 L2 归一化；final 则取 token 均值/标准差拼接后归一化。**这些指标评价的是该汇总向量的几何，不是完整 fused token 的全部信息。**

每个验证频率/相位组合包含四种配色的原图/旋转图，共 8 张。沿用温度 `0.12` 的 supervised contrastive loss；margin 为同向非自身样本的平均余弦相似度减去异向样本的平均相似度。表中取四个组合的平均。

| 留出集几何指标 | 起始检查点 | B0 | B1 |
| --- | ---: | ---: | ---: |
| fused SupCon ↓ | 1.9957 | 1.9947 | 1.9655 |
| final SupCon ↓ | 1.9563 | 1.9697 | 1.2133 |
| fused-final relation 项 ↓ | 0.0006 | 0.0003 | 0.0218 |
| 方向目标合计 ↓ | 3.9527 | 3.9647 | 3.2007 |
| fused margin ↑ | −0.0063 | −0.0062 | −0.0030 |
| final margin ↑ | −0.0020 | −0.0041 | +0.2971 |

方向目标合计为 `fused SupCon + final SupCon + 0.5 × relation MSE`，不包含训练中的蒸馏项及外部权重 `0.2`。B1 的 final margin 在四个留出组合上分别为 `+0.322 / +0.344 / +0.261 / +0.262`，改善并非只出现在单一频率。与此同时，fused margin 仍接近零，relation 项反而增大。

**E18.1 的结论是部分可学习：当前监督能在干净数据上重排 final token 的方向几何，但没有同步塑造 fused，也没有建立一致的跨层几何。**不能说 loss 完全学不动；也不能把真实数据上的失败唯一归因于标签噪声或域复杂性。结果促成 E18.2：冻结下游，把方向目标仅施加在 fused 上。

可复核文件：`e18_1/clean/{protocol,train,validation,train_selection}.json`、`e18_1/{b0,b1}/train_report.json`、`e18_1/probe_{start,b0,b1}/report.json`。每份探针报告均含训练集与验证集几何及逐频率/相位结果。

## E18.2：Fused-only Direction Alignment

代码提交：`179e79f`。作业 `114102` 为 `COMPLETED / 0:0`。结果根目录为 `/share/home/u2515283058/Mymodel/e18_2/`。

### 设置：只新增 B2，冻结 fused 后的全部参数

B2 复用 E18.1 的数据、选择文件、起始检查点和训练预算，只更新 BF stage3/4 与 `token_source_proj.3/4`。当前 fused 是投影后的来源拼接，没有额外可训练融合参数。direct readout、resampler、final token projection、CLIP、BF stage1/2、U-Net、TCPM 全部冻结。

唯一训练目标是 `0.2 × fused SupCon`，使用与 B1 相同的 fused 向量和温度；不含 final loss、relation loss、蒸馏保留损失或任何生成损失。训练仍为 500 步、seed 42、学习率 `2e-5`。B0/B1 直接复用 E18.1 已有结果，未重复训练。

训练后逐张量核验：BF 中 **65 个冻结张量完全不变**，只有 stage3/4 及对应投影的 16 个参数张量变化。U-Net/TCPM 未实例化，检查点内对应内容直接保留，因此 final 的变化只能来自输入 fused 的变化。

### 主结果：fused 仍未形成明显正 margin

| 留出集指标 | B0 | B1 | B2 fused-only |
| --- | ---: | ---: | ---: |
| fused margin ↑ | −0.006201 | −0.003018 | **−0.001783** |
| fused direction loss ↓ | 1.994742 | 1.965511 | **1.956328** |
| final margin ↑ | −0.0041 | +0.2971 | **−0.001382** |

| B2 留出周期数 / 相位 | fused loss | fused margin | final margin |
| --- | ---: | ---: | ---: |
| 4 / 0.11 | 1.954998 | −0.001522 | −0.001335 |
| 4 / 0.36 | 1.955920 | −0.001733 | −0.001349 |
| 10 / 0.11 | 1.958510 | −0.002212 | −0.001444 |
| 10 / 0.36 | 1.955884 | −0.001663 | −0.001399 |

B2 训练 minibatch 的 fused loss 从 `2.0166` 降到 `1.9514`；固定训练集评估的 fused loss 为 `1.9582`、margin 为 `−0.0022`。留出集四个组合的 margin 全部仍接近零且为负。因此不是“训练集方向几何很好、留出集失败”，而是**训练集和留出集都没有形成明显的同向聚集、异向分离**。

辅助方向探针：B2 的 CNN3/4 为 `0.8750`、fused 为 `1.0000`、final 为 `0.9688`。高线性可解码性与当前余弦方向几何目标没有同时改善，再次说明不能把 probe accuracy 当成本轮成功标准。E18.1/18.2 没有新增 `D_rot`、`R_rot` 或完整生成评估。

### 阶段判断与解释边界

E18.2 更接近预设的**结果 3**：在当前 BF 后段更新范围、fused 汇总方式、方向目标和 500 步预算下，冻结 readout 后仍未形成稳定方向几何。现有证据不支持“问题只是方向监督被 readout 吸收，冻结它即可解决”。

B2 同时去掉了 final/relation 与蒸馏项，并冻结 readout，因此该比较检验的是 fused-only 方案整体，不能把差异唯一归因于某一个优化因素。实验只有一个训练种子和小型规则条纹集；结论不能扩大成“BF 在任何监督或训练预算下都不可能学习方向”。

**当前停止 E18.3 与生成阶段，优先重新定义方向敏感的表示/监督，例如显式 gradient、FFT 或 orientation branch。**这是后续方向，尚未实施。已有结果也不足以宣布完整 fused 不含方向信息：线性探针很高，失败的是这套目标所要求的方向几何。
